## About
This project demonstrates how to debounce a button using an STM32. It also tracks button counts and displays them using an LED array.

## Config
For my own notes, the following steps were used after generating the project in CubeMX and opening in VS Code:

1) CTRL + SHIFT + P; STM32: Setup STM32Cube Projects
2) Selected target board and GCC
3) CTRL + SHIFT + P; CMake: Select Configure Preset > debug
4) CTRL + SHIFT + P; CMake: Build (or just CTRL + SHIFT + B)
5) Open debug window (CTRL + SHIFT + D) or F5 to Run and Debug
